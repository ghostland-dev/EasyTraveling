# EasyTraveling

Travel planning SaaS that generates personalised itineraries.

## Features

- Itinerary generation API
- Trip planner and example itineraries
- Authentication and billing pages

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- Google Gemini API

## Getting Started

```bash
git clone https://github.com/ghostland-dev/easy-traveling.git
cd easy-traveling
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: next lint

## Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fghostland-dev%2Feasy-traveling)

Click the button to deploy your own copy on Vercel in one step.

Set these environment variables in the Vercel project settings (see `.env.example`):

- `GEMINI_API_KEY`
- `JWT_SECRET`
